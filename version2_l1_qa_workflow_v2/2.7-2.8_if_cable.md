## IF Cable Routing (2.7 / 2.8) — Near End

### To Do's
- [ ] 200mm bending radius maintained (verify in After photos if visible)
- [ ] Waterproofing on connectors: fully encase connector with heat shrink, self-amalgamating tape, moulded boot, or sealant. No exposed metal or jacket. Coverage should include connector + adjacent cable.
- [ ] Grounding kit installed within 0.5–1 m from cable entry point (if entry point visible)
- [ ] Cable labeling: if cable end is NOT encapsulated (exposed connector/jacket), a yellow ID tag or jacket printing/stamping must be visible. For encapsulated ends, labeling is NOT required.

### To Don'ts
- [ ] Do NOT fail for missing label in one image if it may appear in another → use N_A
- [ ] Do NOT fail based on material color, number of tape layers, or aesthetic; focus on functional coverage
- [ ] Do NOT count watermarks, metadata overlays, on-screen annotations, or IEPMS label stamps as valid cable labels
- [ ] Do NOT fail for cable bundling or crossing differences; IF Cable rules do not penalize routing style
