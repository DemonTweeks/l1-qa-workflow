## Cross-Cutting Rules

These rules apply to all sections unless explicitly overridden by a section's To Don'ts.

- **N_A philosophy**: If a check cannot be verified from the provided images (angle, distance, framing), mark N_A. Never FAIL for unverifiable items.
- **Labeling**: Accept physical ID tags (yellow/white), jacket printing/stamping, alphabet stencil on equipment. Do NOT count watermarks, metadata overlays, on-screen annotations, or IEPMS label stamps.
- **Severity justification**: Every FAIL must include a bbox (when localizable) and a clear description why the requirement is violated.
- **Cross-pair consistency**: When Before and After labels are both visible for the same cable/equipment, they should identify the same endpoints. Mismatch → FAIL. If only one side visible, PASS that check.
- **One photo per component**: Each image verifies only what is visible in it; absence of a label in one photo does not fail if it may appear in another → N_A.
