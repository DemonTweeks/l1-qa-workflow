## IF Cable Routing (3.8 / 3.9) — Far End

### To Do's
- [ ] 200mm bending radius maintained (if visible in photo, verify maintained; if angle/setup doesn't allow verification, mark N_A)
- [ ] Waterproofing on connectors: fully protected from moisture ingress. Accept: heat shrink sleeves, self-amalgamating tape, moulded rubber boots, potting/epoxy, sealant compounds. Must fully enclose connector termination and adjacent cable.
- [ ] Grounding kit 0.5-1m from entry points (if entry point visible, verify distance; if not visible, mark N_A)
- [ ] Cable labeling:
  - If cable end is NOT encapsulated (exposed connector and cable), a yellow ID tag must be physically attached or jacket printing/stamping visible.
  - If cable end IS encapsulated, **no label check required** — focus on waterproofing. If encapsulation visible and complete, mark N_A for labeling.

### To Don'ts
- [ ] Do NOT fail based on material color, number of layers, or aesthetic
- [ ] Do NOT count watermarks, metadata overlays, on-screen annotations, IEPMS label stamps as valid labels
- [ ] Do NOT fail for cable bundling/crossing; IF Cable rules do not penalize routing style
