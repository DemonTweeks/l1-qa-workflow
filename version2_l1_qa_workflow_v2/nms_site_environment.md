- [ ] Provide 4 comprehensive site environment photos from different angles/views (e.g., corner views for indoor spaces, overall site views for outdoor/shelter installations). Aim for at least 4 distinct perspectives; if fewer are provided, note N_A for missing angles but do not auto-fail if available photos otherwise cover the installation context.
- [ ] Photos must be clear, GPS-enabled, and include an accepted IEPMS watermark in each image. A blurry watermark is acceptable as long as there are visible traces.
